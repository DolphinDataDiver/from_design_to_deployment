# from_design_to_deployment
this repository document the proccess of designing&amp;planning a network deployment from scratch/



# log 1: 24/10/2026:
The main purpose of this project is to bridge the gap between theoretical knowledge of CCNA and actual network deployment
in the real world. We have seen that the industry has many solution manual and best practices or other technical 
documentation linked with networking infrastructre. knowledge of CCNA topic is not sufficient to ensure adequate 
integration into the workforce.

We started by looking for manuals that detail a systematic approach toward networking design for companies.
////////
the Top-Down Network Design
Third Edition Priscilla Oppenheimer
///////////
will be used for that purpose and accompanied manual cisco lifecycle will also be used.
